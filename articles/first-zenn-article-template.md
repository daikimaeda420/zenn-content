# この記事について

このファイルは、Obsidian の `05_Public/zenn/` にある下書きを Zenn 公開用へ移すときのテンプレートです。公開前提で整えた内容だけを残し、メモや途中経過は持ち込まない運用を想定しています。

## 使い方

1. Obsidian 側の下書きから、公開する本文だけをこのファイルに移す
2. frontmatter の `title`、`emoji`、`topics`、`published` を更新する
3. Obsidian 特有のメモ記法や内部リンクを削る
4. `npm run preview` で表示を確認する
5. 公開するときに `published: true` に変更する

## 公開前チェック

- [ ] タイトルが公開用になっている
- [ ] `topics` が 1〜5 個の範囲で設定されている
- [ ] 誤字、リンク切れ、画像参照ミスがない
- [ ] 非公開メモや作業メモが残っていない
- [ ] 見出し構成が読みやすい
